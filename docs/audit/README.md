# Аудит CeZeOs

Общий аудит CeZeOs и Aquamarine лежит в репозитории Aquamarine: `docs/audit/`. Там карта архитектуры, реестр дефектов и пакет для независимого аудита.

Здесь — то, что относится только к CeZeOs.

| ID | P | Суть | Статус |
|---|---|---|---|
| CZ-SEC-001 | P0 | Demo-вход через подменённый `Host`; демо-данные в production | Исправлено в PR #1, тест `production.test.mjs` |
| CZ-SEC-002 | P1 | Wiki: любую статью может править любой участник; нет удаления и модерации (`server.mjs:506-522`) | Исправлено в ветке `claude/wiki-permissions` (`wiki.mjs`): четыре режима на уровне сообщества и страницы, защита страниц, предложения, сравнение, откат, журнал; права проверяются на сервере. Тесты `cezeos.test.mjs` («wiki: …»): режимы, обход прав через API (в том числе роли после выхода из сообщества — найдено и исправлено при проверке), одновременные правки и откаты. Хранимый XSS — `tools/wiki-xss-check.cjs` (Playwright): не выполняется. Удаления статей нет — только откат. Wiki между Регионами не распространяется |
| CZ-SEC-003 | P1 | Нет rate limit. MIME файла проверяется по заявленному типу, а не по содержимому. Тело запроса до 32 МиБ целиком в памяти | Открыто |
| CZ-PERF-001 | P2 | Лента читает таблицу без LIMIT и фильтрует в JS; N+1 — 7–11 запросов на пост; пагинации нет (`server.mjs:320-330`, `159-171`) | Открыто |
| CZ-PERF-002 | P2 | Поиск профилей загружает в память все профили (`server.mjs:414`) | Открыто |
| CZ-DB-001 | P2 | Нет миграций (`user_version`). Нет индексов `posts(author)`, `posts(group_id)`, `posts(kind)`, `reactions(post)` | Открыто |
| CZ-MEDIA-001 | P2 | Медиа хранятся в BLOB в SQLite. Ответ на Range-запрос всё равно загружает в память весь объект | Открыто |

**Как проверить:** `npm test` (Node ≥ 22.5, `node:sqlite`).
